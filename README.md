# timer

A simple timer in 14 lines of codes using python

# features

- Set a custom countdown time
- Displays the remaining time
- Automatically stops when the timer reaches 0
- Lightweight and easy to use

# built With

- Python
- time module

# how to Use

- run the program :
timer.py

- enter the amount of time you want, and the timer will count down until it reaches 0.

# what I Learned

- This project helped me practice loops, user input, and using Python's time module.
